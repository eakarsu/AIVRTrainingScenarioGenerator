# Operations

Copy `.env.example` to `.env`, replace placeholders, provision PostgreSQL and dependencies, then run `cd backend && npm run migrate`. Start from the repository root with `./start.sh`.

Startup never installs, seeds, migrates, creates credentials, starts system services, or kills ports. It fails closed on missing secrets or schema. Run `npm test` in `backend`. Unity, Unreal, WebXR, storage, CDN, transcription, translation, and publishing are modeled through typed delivery receipts with retries/dead letters; no real platform connection, rights clearance, or accessibility certification is claimed without a separately configured adapter and human review.

The legacy seed is destructive and guarded by `ALLOW_DESTRUCTIVE_DEMO_SEED=true`; use it only for an isolated disposable database.
